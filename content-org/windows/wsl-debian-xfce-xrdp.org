之前都是使用虚拟机来安装 Linux 系统，使用 WSL 安装 Linux 系统确实比较方便，安装上桌面以后也可以达到
以前虚拟机的功能：

* 安装 WSL Debian

 通过以下点命令来安装：

#+begin_src shell
wsl --install -d debian --name debian --location D:\VirtualBoxVMs\WSL\Debian
#+end_src

#+begin_src shell

正在安装: Debian GNU/Linux
已成功安装分发。可以通过 “wsl.exe -d debian” 启动它

Please create a default UNIX user account. The username does not need to match your Windows username.
For more information visit: https://aka.ms/wslusers

#+end_src

中间会提醒输入新的账号：

#+begin_src shell

#+end_src

输入新的账号以及输入两次密码后安装完成。

先备份老大配置文件：

#+begin_src shell
sudo cp /etc/apt/sources.list /etc/apt/sources.list.backup
#+end_src

在如下的网址中 https://mirrors.tuna.tsinghua.edu.cn/help/debian/ ，安装图中 1,2 标示的选项后，将 3 中的
文本复制出来。

#+ATTR_HTML: :width 90%
[[file:../../static/images/wsl-debian-xfce-xrdp.org/2026-01-28_16-06-22_screenshot.png]]

通过以下命令修改文件内容：

#+begin_src shell
sudo vi /etc/apt/sources.list
#+end_src

先删除其中的所有内容，然后把上面网址中的内容（我把 https 改成了 http）粘贴到这个文件并保存，然后执行以下命令：

#+begin_src shell
sudo apt update
sudo apt upgrade
#+end_src

* 安装 XFCE 桌面

#+begin_src shell
sudo apt install xfce4 xfce4-goodies
#+end_src

* 安装 Dbus

#+begin_src shell
sudo apt install -y dbus dbus-x11
#+end_src

* 安装 XDRP

#+begin_src shell
sudo apt install xrdp
#+end_src

执行如下命令来修改配置文件：

#+begin_src shell
sudo cp /etc/xrdp/xrdp.ini /etc/xrdp/xrdp.ini.bak
sudo sed -i 's/3389/3390/g' /etc/xrdp/xrdp.ini
sudo sed -i 's/max_bpp=32/#max_bpp=32\nmax_bpp=128/g' /etc/xrdp/xrdp.ini
sudo sed -i 's/xserverbpp=24/#xserverbpp=24\nxserverbpp=128/g' /etc/xrdp/xrdp.ini
#+end_src

将账号添加到 Group 中：

#+begin_src shell
sudo usermod -a -G ssl-cert xrdp
#+end_src
