# 模型推荐按显存分档，不写死具体标签

Ollama 章节的"模型选型"一节按硬件档位（核显/CPU、6-8G、12-16G、24G+）分档推荐，每档给 2-3 个标签；不用"推荐装某某模型"的写法。

Ollama 的模型库更新极快（gemma3、gemma4、qwen3、qwen3.5、qwen3.6 在近一年内依次上位），任何写死的标签都会在几个月内过时，读者照抄时要么拉不到、要么早已不是最优。按档位写则只需在标签淘汰时替换同一档内的名字，表格骨架与判断逻辑长期有效。磁盘体积用实测值并注明采集日期，读者能自行换算新模型。

## Consequences

- 该节需要维护，但维护成本是"替换单元格"而非"重写整节"。
- 文中必须教读者自己判断的方法（`ollama show` 看量化、`ollama run --verbose` 看 tok/s），而不只是给结论。
